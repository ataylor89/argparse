Steps for implementing the RSA algorithm
----------------------------------------
1. Create a new branch in my [argparse](https://github.com/ataylor89/argparse) repository, called "rsa" or "rsa-algorithm"
2. Create a new folder, argparse/src/rsa, which will contain the Python implementation
3. Write the first file, argparse/src/rsa/primegen.py, which will generate prime numbers on demand
4. Write the second file, argparse/src/rsa/keygen.py, which will generate a key pair (a public key and a private key) on demand
5. Write the third file, argparse/src/rsa/rsa.py, which will have functions for encrypting and decrypting a message, in addition to a command-line interface for encrypting and decrypting a message
6. Write the fourth file, argparse/src/Keygen.java, which will be a Java binding for argparse/src/rsa/keygen.py
7. Write the fifth file, argparse/src/Rsa.java, which will be a Java binding for argparse/src/rsa/rsa.py
8. Test the Java code and the Python code, to make sure that it works properly
9. Update changes.txt, branches.md, and README.md, to reflect the changes
10. Celebrate! :)
